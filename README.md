# RESULT_CALCULATOR - PYTHON PROJECT

Student ke marks se Percentage , Grade aur Class Topper nikalnae wala Python project.

## kya karta hai ye Project?
- Student ka name , roll number aur 4 major subjects ke marks leta hai
- Total marks aur Percentage nikalta hai
- Percentage se Grade deta hai- A+ , A , B, C, D, FAIL
- Sabse zyada marks wale student ko class Topper batata hai

## kaise chalaye?
1. 'RESULT_CALCULATOR.py' file kholo
2. Run dabao
3. Name aur marks daalo , result mil jayega
